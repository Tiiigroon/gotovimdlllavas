# Выбор салата для комплексных обедов

## Что изменится
- При нажатии «Добавить» у любого комплекса откроется короткое окно с выбором: добавить салат или оставить комплекс без салата.
- Для понедельника будет предложен салат оливье, для вторника — салат с крабовыми палочками.
- Порция салата будет стоить 3 BYN и отображаться отдельной строкой в корзине, чтобы итоговая сумма считалась правильно.
- Выбор будет доступен для обоих комплексов каждого дня и на русском, и на английском.

## Проверка
- Проверить добавление комплекса без салата и с салатом.
- Убедиться, что салат прибавляет ровно 3 BYN за каждую порцию и корректно меняется в корзине.
- Проверить окно выбора и корзину на компьютере и телефоне.

## Технические детали
- Добавить сведения о доступном салате в данные комплексных обедов.
- Использовать существующее диалоговое окно и элементы кнопок сайта.
- Хранить комплекс и салат как отдельные позиции корзины с уникальными идентификаторами по дням.
